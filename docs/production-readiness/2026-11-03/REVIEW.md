# FacadeProxy review

## Scope and verdict

**Revision:** `18e71301f9c37b21101deb3f111deba0d3124dfc` on `main`. **Stage:** implemented browser-extension/Rust-proxy hardened prototype, not a verified production release. The [README](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/README.md#L3-L30) describes a local-first persona tool and explicitly disclaims anonymity and complete fingerprint protection. The [readiness document](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/docs/PRODUCTION_READINESS.md#L20-L35) gives self-assessed scores; this review does not validate them.

Static sampling identifies exploitable-looking control-origin acceptance and multiple coherence gaps; actual exploitability and browser behavior require independent runtime reproduction. CI and release were recorded failing at this revision. **Runtime, builds, tests, security scans, signing, and publication: NOT RUN**, as required by the author contract. See [remediation plan](REMEDIATION_PLAN.md).

## Architecture and product boundary

The [manifest](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/public/manifest.json#L7-L48) wires an MV3 background worker, all-frame MAIN and isolated scripts, a popup, proxy permissions, and broad host access. The [background](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/background/background.ts#L152-L196) posts the persona, sets PAC and DNR, then broadcasts it. The [Rust binary](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/main.rs#L51-L93) loads configuration and starts the proxy; [routing](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L94-L131) distinguishes control endpoints, CONNECT, and HTTP forwarding. CONNECT tunnels rather than intercepting TLS; DNR is therefore important for HTTPS headers. Browser APIs, local ports, Rust/Tokio/Hyper and Node tooling are external dependencies; no hosted service is evidenced in inspected entry points.

## Findings ledger

**F1 — High, confirmed static; browser exploitability unverified: origin prefix is not a host check.** [`proxy/src/proxy.rs:542-560`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L542-L560) allows `starts_with("http://localhost")` and analogous loopback prefixes, so `http://localhost.attacker.example` passes the predicate. The inspected `/personas` synchronization handler applies it before token checking ([lines 184–198](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L184-L198)); the `/persona` POST checks are separately visible at [lines 269–284](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L269-L284). Absent/empty configured tokens permit access ([lines 574–590](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L574-L590)), conflicting with the [stated security policy](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/SECURITY.md#L27-L32). This finding covers these inspected handlers, not every mutation route. A suitably named remote origin could be authorized by the server if browser/network restrictions permit the request; configured tokens still gate mutation. Parse exact origin hosts and require an explicit trusted-extension/token policy.

**F2 — High, confirmed static; impact scoped to the page: page messages can override the persona.** [`injected.ts:412-420`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/injected/injected.ts#L412-L420) accepts same-window messages with `source: 'facadeproxy'` and calls `applyPersona` or `restoreOriginals`; page scripts can construct those messages. This bypasses the [claimed readiness gates](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/README.md#L72-L84) within that document, creating inconsistent JS and network signals. No privileged extension or proxy mutation is established. Redesign the page/extension boundary, then test hostile page messages and rollback.

**F3 — High, confirmed static; activation timing unverified: bootstrap trusts proxy state alone.** [`injected.ts:89-107,409-410`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/injected/injected.ts#L89-L107) synchronously applies a reachable proxy's persona, independently of PAC/DNR readiness. The [background posts before configuring PAC and rules](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/background/background.ts#L170-L189), and an initial proxy persona is also possible ([main.rs:22-24,80-85](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/main.rs#L80-L85)). A navigation during partial setup or with an independently configured proxy can therefore receive JS spoofing without proof of network readiness. Establish an authenticated, coherent activation epoch; verify it under delayed and failed setup.

**F4 — Medium, confirmed static: timezone offset ignores the date.** [`injected.ts:164-196,241-249`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/injected/injected.ts#L164-L196) returns fixed Amsterdam `-120` unless an explicit offset is supplied, then returns that same offset for every `Date`. Winter and historical dates can disagree with the advertised timezone and site calculations. Derive offsets per instant with timezone rules or explicitly narrow the feature; validate winter, summer and transition instants.

**F5 — Medium, confirmed static: E2E header assertion does not exercise proxy forwarding.** The [test server binds and navigates to `127.0.0.1`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/e2e/facadeproxy.spec.ts#L78-L109), while [PAC returns `DIRECT` for that host](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/background/background.ts#L417-L424). Assertions [check headers](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/e2e/facadeproxy.spec.ts#L30-L40), but DNR can modify them without the proxy. This test is useful for early JS and header output, not proof of forwarding or tunnel behavior. Add an observable non-bypassed route and a proxy-negative control.

**F6 — High release blocker, historical CI plus confirmed static scaffolding.** The snapshot records [CI failure](https://github.com/knarayanareddy/FacadeProxy/actions/runs/27418415295) and [release workflow failure](https://github.com/knarayanareddy/FacadeProxy/actions/runs/27418413444), both on the pinned SHA; job logs and causes were not inspected. [Release workflow](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/.github/workflows/release.yml#L73-L104) labels macOS/Windows signing placeholders and explicitly exits 1 when those jobs run. Its [draft release](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/.github/workflows/release.yml#L106-L130) depends only on unsigned artifacts, not signing. Do not infer the recorded failures were caused by those placeholders. Repair observed failures and require verified release evidence.

## Five-discipline assessment

Additional exact source anchors for the ledger: F2's check is `data.source !== 'facadeproxy'` in its cited message handler. F3's actual bootstrap invocation is [`if (synchronousPersona) applyPersona(synchronousPersona)` at injected.ts:409–410](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/injected/injected.ts#L409-L410), separate from the loading function. F4's fixed-offset application is [injected.ts:241–249](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/injected/injected.ts#L241-L249). F6's signing scaffold explicitly contains `exit 1`, while the release depends on `needs: unsigned-reproducible-artifacts`, in the two workflow ranges linked above.

- **Correctness:** F2–F4 affect the central coherence promise. CONNECT [connects upstream before returning success](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L374-L421), a useful static safeguard, not runtime proof.
- **Automation/testing:** F5 limits the sampled Chromium test; [CI](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/.github/workflows/ci.yml#L10-L27) specifies extension checks and [a three-OS Rust matrix and browser E2E](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/.github/workflows/ci.yml#L29-L66). F6 prevents treating their configuration as a pass.
- **DevOps:** F6 blocks a release claim; clean-machine reproducibility, signing, actual rollback and persona-file recovery are unverified. No server deployment architecture is assumed.
- **OWASP/security:** F1 is an authorization/origin flaw; F2 is a page-message trust-boundary flaw. Tokenless startup warns but continues ([main.rs:87-89](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/main.rs#L87-L89)). [`/persona/current`](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/proxy/src/proxy.rs#L168-L181) deliberately returns the full active persona with wildcard CORS: assess custom-persona exposure, not a proven history leak. Logs, credential persistence, input-size limits and supply-chain integrity remain unverified. CI installs audit tools and generates SBOMs ([ci.yml:68-93](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/.github/workflows/ci.yml#L68-L93)); versions and provenance of all fetched tools/actions need review, not assumed CVEs.
- **UI/UX/accessibility:** The [badge](https://github.com/knarayanareddy/FacadeProxy/blob/18e71301f9c37b21101deb3f111deba0d3124dfc/extension/src/background/background.ts#L560-L577) uses `ON`, `!`, and `ERR`, but F2/F3 make an `ON` state insufficient evidence of coherent page behavior. Popup implementation, keyboard navigation, screen-reader announcements and contrast were not inspected or tested; no accessibility compliance claim is warranted.

## Owner decisions and production blockers

No production certification is implied.
